## ORIGIN

PROJECTKIDCREATIONS started as a refusal.

The gel-blaster market in the mid-2020s was dominated by mass-imports — sealed builds, locked supply, marketing-heavy brands selling re-skins of the same handful of chassis molds. If you wanted to mod, you bought aftermarket from a competing brand that operated the same way. The maker side of the scene — the people running well-tuned printers, the people designing chassis in Fusion at 2 AM, the people printing their own parts — existed but had no center.

PKC was founded to be that center.

The thesis from day one: **gear should be built, not bought.** Every chassis, every modular kit, every aftermarket part lives as a 3D-printable file first. Files are documented, dimensioned, tested. The maker keeps control. The brand is the design language, not the supply chain.

This isn't anti-purchase. PKC sells finished kits, sells drops, sells materials. But the commitment is to **make the file path possible alongside the buy path**. Every drop ships with the option to print yourself.

That's the rebellion. Open source, productized.

## MILESTONES

A living timeline of where PKC has been. Updated as the brand grows.

### 2026-04-23 — v0.1.0 brand system shipped

The PKC tactical brand system locked: locked type pair (Archivo Black + JetBrains Mono), locked 5-color palette (tactical-black, hi-vis-orange, anodized-slate, ghost-grey, concrete-white), locked voice (streetwear / phonk / collector). Stripped MD3 token scaffold from the design system; brand-only tokens from there forward. Repo went private at `AlxanderArt/PKCDesignSystem`.

### 2026-05-02 — Repo split: design system + product layer

PKC split into two repos: `AlxanderArt/PKCDesignSystem` (system layer — tokens, brand-md, figma-spec) and `AlxanderArt/ProjectKidCreations` (product layer — onboarding micro-flow, future apps). Cleaner separation between brand-as-substrate and brand-as-application.

### 2026-05-12 — Verified state introduced

The neon-green `#39FF14` accent was sanctioned for verified-state UI (Phase 4 profile dashboards, VIP role color, certain badges). Hi-vis-orange remains the in-progress / onboarding accent. Two-half accent system: orange = building, green = built.

### 2026-05-14 — PROJECTKIDCREATIONS Discord server launches

The community gets a home. Server built from scratch with the Top Shooter bot, 7 categories, 30+ roles, full Onboarding flow, AutoMod, and this living server guide. PK Blick is the founding Owner; staff additions over time.

## FOUNDER NOTE

*From PK Blick — Founder, PROJECTKIDCREATIONS.*

If you're reading this, you're standing somewhere I imagined this server being a long time before it existed. So — welcome. I mean that.

PKC isn't a hobby project that grew into a brand. It started as a brand. The thesis came first. The design system came before the first physical drop, because I wanted to know what PKC *was* before I started shipping things in its name. Every drop, every file, every channel in this server has to pass a test — does it reinforce *Engineered Rebellion*, or does it dilute it?

The reason that test matters is because brands that don't have a thesis end up shaped by whoever shouts loudest. The market shouts loudest. The market wants you to make a brand that sells more units this quarter. PKC's job is to make a brand that lets people **build better than the market makes available** — that's it. If we sell drops along the way, good. If we ship paid kits, great. But the file path stays open, the maker stays in control, and the rebellion stays engineered.

The server is the part of the brand where you and I are in the same room. I'm in here. Mods are in here. Designers are in here. We're not customers and a brand. We're operators on the range.

A few asks, in trade for the work I've put in to make this exist:

- **Read the rules.** Not as a formality. Knowing them means we don't have to enforce them on you.
- **Build something.** Even if you're not a maker today — pick a file from `#print-files`, send it to a printer, hold the part in your hand. That's the whole point of this place.
- **Be patient with the bot.** Top Shooter is custom-built; it grows in phases. Some features come later. If something feels missing, ping me.
- **Push back when I'm wrong.** That's how brands stay sharp.

Thanks for showing up.

— **PK Blick** · Founder, PKC · 2026-05-14
