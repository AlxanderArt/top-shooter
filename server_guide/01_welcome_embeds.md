## Embed 02 — What this server is

**Color:** `#3F4448` (anodized slate)
**Marker:** `<!-- pkc-embed-id: 02 -->`

**Title:** `WHAT THIS SERVER IS.`

**Description:**
> PROJECTKIDCREATIONS is two things stacked: a **product brand** and a **maker community**.
>
> **The product**: 3D-printable chassis, modular kits, and aftermarket parts for gel-blasters. Designed by PKC, printed by you. Released as paid drops and free open files.
>
> **The community**: operators who run PKC gear, makers who print and remix, collectors who follow the drops. The server is where they all overlap.
>
> If you build, post in `#build-help` and `#showcase`. If you collect, watch `#drops`. If you lurk, `#off-topic` is the door — everyone's welcome on the range.

## Embed 05 — 60-second quickstart

**Color:** `#FF5F1F` (hi-vis orange)
**Marker:** `<!-- pkc-embed-id: 05 -->`

**Title:** `60-SECOND QUICKSTART.`

**Description:**
> 1. Read **#rules**. React with the green check to acknowledge.
> 2. Complete **onboarding** (5 short questions). The flow appears on join. If you skipped it, server name dropdown → "Edit your tags" reopens it.
> 3. Say hi in **#off-topic** — the only channel chattable to new joins. Talk there until you hit @New Shooter.
> 4. Watch **#drops** for releases. Pick up `Pings · Drops` in onboarding to never miss one.
> 5. Read the deeper guide in **`#server-guide`** at your own pace.
>
> That's it. Welcome.
