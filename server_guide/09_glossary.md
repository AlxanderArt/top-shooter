PKC-specific terms, gel-blaster scene terms, and the maker-shorthand that gets thrown around. Defined plainly.

## PKC TERMS

**PKC** — `PROJECTKIDCREATIONS`. The brand. Pronounced as letters: "P-K-C."

**Engineered Rebellion** — PKC's two-word brand thesis. "Engineered" = designed to spec. "Rebellion" = refusing the buy-only mainstream supply chain. See `#server-guide` → Brand Story.

**The range** — colloquial for the PKC server / community. "Welcome to the range" = welcome to PKC. Origin: tactical-brand voice + a literal nod to where operators actually use this gear.

**New Shooter** — an active community member; also the role you earn after Level 20 or mod promotion.

**Verified Builder** — a member who's passed the standing PKC build challenge. Trusted to post files in `#print-files`.

**Drop** — a PKC product release. Numbered sequentially (`DROP-001`, etc.). Can be open file (free), paid kit, or build-along event.

**Drop pipeline** — the staged rollout: staff teaser → Beta Tester preview (day -7) → VIP early access (day -1) → public release (day 0).

**Mk-series** — PKC's chassis numbering. `Mk1`, `Mk2`, etc. Each Mk is a chassis generation.

**Livery** — the paint scheme / decal pattern on a build. PKC's reference livery is tactical-black base with hi-vis-orange accents at the 70/20/10 ratio.

**The standing challenge** — the PKC build challenge to earn @Verified Builder. Always open; spec is fixed (unless staff updates it).

**Open file** — a free, public PKC STL drop. As opposed to paid kits.

**Build-along** — a quarterly event where staff releases a file and the community builds it together over a week, with daily stage check-ins.

## GEL-BLASTER SCENE TERMS

**Gel-blaster** (or just "gel") — projectile launcher firing water-absorbing gel pellets ("gels"). Functions similarly to airsoft but uses biodegradable hydrogel ammo.

**Gel** — the hydrogel ammo itself. 7–8mm beads, soaked before use.

**FPS** — feet per second; muzzle velocity. Local-law-regulated in many regions.

**Hop-up** — barrel system that puts backspin on the projectile for stable flight. Adjustable on most builds.

**AEG** — Automatic Electric Gun. Battery-driven motor cycles the gearbox. The most common gel-blaster type.

**GBB / Gas-Blowback** — gas-powered gel-blaster with a working blowback mechanism. Realistic recoil feel.

**M4-pattern / Glock-pattern / AR-pattern** — body styles that mimic real-firearm form factors. PKC chassis are designed against specific platform patterns so off-the-shelf mags / receivers fit.

**Mag adapter** — accessory part that lets you run mags from one platform in a different-platform body.

**Loadout** — full kit a member runs: chassis + optic + mag + accessories.

**Range** — the place you actually shoot. PKC's voice uses "the range" to mean both the literal location and the community.

**Eye-pro** — eye protection. Required for all gel-blaster activity. Non-negotiable safety floor.

**Receiver** — the structural body of the gel-blaster. Often where PKC chassis files replace OEM parts.

## 3D-PRINTING TERMS

**FDM** — Fused Deposition Modeling. Filament-extrusion printing. Most common (Bambu, Prusa, Ender, Voron).

**SLA / Resin** — Stereolithography / resin printing. Higher detail, smaller build volume. Used for accessory parts on PKC builds.

**STL** — the standard 3D-print file format. Mesh of triangles.

**3MF** — newer 3D-print format. Includes color, material, and print-setting metadata.

**STEP** — CAD source format. Editable in Fusion / SolidWorks. PKC includes STEPs on open files for makers who want to modify.

**Layer height** — vertical resolution of a print. 0.20mm is default for FDM chassis. 0.12mm for high-detail.

**Infill** — internal lattice density. 25% gyroid is PKC default for structural parts.

**Walls** — perimeter shell count. 4 walls for load-bearing parts.

**Supports** — temporary structures that prop up overhangs. Tree supports are usually best for PKC files.

**Brim** — wide first layer that helps print adhesion. Used for narrow contact patches.

**Raft** — a thicker base under the print for problematic first layers. Usually unnecessary for PKC chassis.

**PETG** — strong, flexible, UV-resistant filament. PKC default.

**ASA** — ABS-like, UV-stable. PKC recommended for outdoor / hot environments.

**PA-CF** — Polyamide with Carbon Fiber. Premium engineering filament. For high-stress builds; requires specific printers.

**Dialed-in** — a printer that's been calibrated correctly for the material it's running. "Dialed-in" prints come out clean.

**Print fail** — when a print goes wrong. Posted in `#print-files` thread `Print-Fails` tag, or in `#build-help` for diagnosis.
