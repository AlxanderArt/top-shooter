This thread covers: **how to reach a mod, how to report a member, how to appeal a moderation action, and what mods can / can't do.**

## REACHING A MOD

The mod team prefers **issues to be raised in the right channel rather than via mass DM**. Three escalation tiers:

### Tier 1 — Channel issue (low urgency)
Something off-topic, slightly out of line, or a thread that needs cleanup.

→ React with the **🚩 flag emoji** on the message. Mods scan for flags in their daily sweep. No DM needed.

### Tier 2 — Active problem (medium urgency)
Someone is harassing, posting spam, leaking, or breaking rules in real time.

→ Use Top Shooter's **`/report <user> <reason>`** slash command (available in any channel you can post in). The report goes directly to `#mod-chat` as an embedded alert with a link back to the offending message. Mods see it within minutes during active hours.

> **Note:** `/report` requires Phase 3 (Moderation cog) of the Top Shooter build to be live. If `/report` isn't available yet, **DM any @Mod directly** with a link to the message.

### Tier 3 — Sensitive issue (high urgency / privacy needed)
Threats, doxxing attempts, severe harassment, anything you don't want public.

→ **DM the @Mod role**: right-click any user with the @Mod role and Send Message. All @Mod-role holders are reachable; DM any one of them. They escalate internally if needed.

→ If no @Mod is online, DM the **@Founder** role. Founders are the last-line escalation.

## REPORTING A MEMBER

A good report includes:

1. **Who** — mention or user ID (right-click → Copy User ID, with Developer Mode on).
2. **What** — what rule was broken. Reference the rule number from `#rules`.
3. **Where** — link the message (right-click the message → Copy Message Link).
4. **When** — if not immediate, timestamp or approximate time.
5. **Evidence** — screenshot if the message might get deleted before mods see it.
6. **Pattern** — if this is repeated behavior, note it.

A bad report ("X is being annoying") gets less mod attention than a precise one. Be specific.

## WHAT MODS CAN DO

- **Delete messages** (own discretion, must include action in `#audit-log`).
- **Timeout** a member (up to 7 days via Discord; longer with role-based mute).
- **Kick** a member (they can rejoin if not banned).
- **Ban** a member (subject to staff sync — see below).
- **Add or remove member roles** (with the exception of staff-only roles, which require @Founder+).
- **Manage threads** (lock, archive, delete).
- **Run AutoMod overrides** (whitelist/unblock a flagged message).
- **Pin** important messages.
- **Move** threads between forum channels.

## WHAT MODS CANNOT DO (UNILATERALLY)

- **Ban a member who's @Verified Builder or higher** — requires 2-mod or 1-mod-plus-Founder agreement, documented in `#mod-chat`.
- **Permanent server-wide channel locks** — requires @Founder.
- **Modify server settings** (channels, categories, roles, automod rules) — staff infrastructure changes go through @Founder / @Owner.
- **Change a drop schedule** — drops are owned by @Designer + @Founder.
- **Issue refunds or process payments** — that's Founder/Owner only.

## APPEALS

If you were timed out or banned and think it was in error:

### Timeout appeal
Wait out the timeout. After it expires, DM the mod who issued the timeout (their name is in the timeout notification you received). Be civil. They'll review their notes from `#audit-log` and either explain the call or reverse it.

### Ban appeal
- For temporary bans, wait it out. The ban notification includes an end date.
- For permanent bans, you can't DM the mods (you've been kicked out of the server). Email **appeals@projectkidcreations.io** with:
  - Your Discord username + ID
  - The reason given for the ban (if you remember)
  - Your case for reinstatement
- Founder reviews appeal emails monthly. **Most appeals are not granted.** Bans happen because mods have seen patterns; an apology email doesn't change the pattern.
- **Ban evasion** (creating an alt to rejoin) makes the original ban permanent and unappealable. Don't do it.

## FILE A REPORT WITH DISCORD ITSELF

For things that violate **Discord's Terms of Service** (harassment, doxxing, illegal content), use Discord's built-in report flow in addition to telling PKC mods:

- Right-click the message → Report
- Discord's Trust & Safety team reviews separately from PKC mods

PKC mods can ban from the server. Discord can ban the user from the platform entirely.

## MOD CONDUCT EXPECTATIONS (FOR TRANSPARENCY)

The mod team operates under these rules:

1. **Document every action in `#audit-log`** with reason. Top Shooter handles most of this automatically.
2. **No mod actions against personal disputes.** A mod can't timeout someone they're feuding with in DM. They escalate to another mod.
3. **No public callouts.** Mod-action notifications go to the affected user via DM, not in-channel.
4. **No favoritism toward @Verified Builder or @VIP.** Higher-tier members get the same rule enforcement as anyone else.
5. **Two-mod review on bans of established members** (@Verified Builder+).
6. **Appeals are heard, even when not granted.**

If a mod violates these expectations, DM @Founder. Mods are members of the community and they're accountable to it.
